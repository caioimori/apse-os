# Story 0.1 — Bootstrap monorepo + toolchain

## Contexto
Primeira story do projeto. Sobe scaffolding completo seguindo ADRs 001, 002, 004, 006. Nada roda ainda — só infra.

## Acceptance Criteria

### AC1 — pnpm workspace funcionando
**Given** repo vazio com `pnpm-workspace.yaml`
**When** executa `pnpm install`
**Then** workspace reconhece `apps/*` e `packages/**/*` e resolve sem erro

### AC2 — Next 15 em apps/web
**Given** workspace configurado
**When** executa `pnpm dev`
**Then** Next 15 sobe em `localhost:3000` com TypeScript, Tailwind v4, App Router, src-dir, `@/*` alias

### AC3 — Supabase local up
**Given** Docker Desktop rodando
**When** executa `supabase start`
**Then** Postgres sobe em `:54322`, Studio em `:54323`, Auth em `:54321`

### AC4 — Biome configurado
**Given** `biome.json` no root
**When** executa `pnpm lint` e `pnpm format`
**Then** valida todo o repo sem erro de config

### AC5 — dependency-cruiser bloqueia violação
**Given** `.dependency-cruiser.cjs` com regra `no-cross-module-internal`
**When** alguém importa `@apse/modules-X/domain` em outro módulo
**Then** `pnpm depcheck` falha com erro claro

### AC6 — CI GitHub Actions verde
**Given** workflow `.github/workflows/ci.yml`
**When** push em qualquer branch
**Then** roda: install → typecheck → lint → depcheck → build (tudo passa)

### AC7 — Design tokens disponíveis
**Given** copy de `sinapse-plataform/src/app/globals.css` → `packages/shared/ui/styles/tokens.css`
**When** `apps/web/src/app/layout.tsx` importa tokens
**Then** página root usa `bg-[var(--surface-base)]` e `text-[var(--text-primary)]` corretamente em light + dark

### AC8 — Secret scan no pre-commit
**Given** husky + secretlint configurados
**When** tenta commitar `.env` com `sk-ant-` ou `SUPABASE_SERVICE_KEY`
**Then** commit é bloqueado

### AC9 — Preview Vercel funcionando
**Given** repo conectado no Vercel
**When** push em branch
**Then** preview deploy sobe e renderiza página inicial Next 15

## Scope IN
- Monorepo pnpm (`apps/`, `packages/`)
- Next 15 em `apps/web`
- Supabase local via Docker

- Tokens caioimori-DS em `packages/shared/ui/styles/`
