# Story 4.1 — Contracts + Pricing

## Contexto
Coração do produto. Contrato amarra cliente a receita mensal e splits (custos de freela, ferramentas, impostos, partição sócios). Preview de margem antes de fechar.

## Acceptance Criteria
1. Migration `contracts` + `contract_splits` com RLS por org_id
2. Domain puro `calculateMargin(contract, splits) → { gross, totalCostCents, netCents, marginPct }`
3. API módulo `@apse/modules-contracts`: list, get, create, update, end, listByClient
4. Preview de margem em tempo real no form (client-side via domain re-export)
5. Splits suportam `pct` (0-100) OU `amount_cents` (fixo)
6. Kind de split: `revenue_share | collaborator | tool | tax | other`
7. Tela `/orgs/[id]/contracts` lista + filtro por status
8. Tela `/orgs/[id]/clients/[clientId]` passa a mostrar contratos do cliente
9. Form cria contrato + até 10 splits em única transação
10. Contract tests cobrem shapes + margin calc + edge cases (split 0%, split > 100%)

## Scope IN
- Migration 0004
- `@apse/modules-contracts` com api + domain (pricing)
- Páginas de lista/criar/detalhe
- Integração com `@apse/modules-clients` via `/api` (sem cross-import de domain)

## Scope OUT
- Edição de splits após criação (cria novo contrato pra mudar)
- Reajuste automático
- Múltiplas moedas (BRL only)
- Contratos não-recorrentes (one-shot) — futuro
