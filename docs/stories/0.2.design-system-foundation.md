# Story 0.2 — Design system foundation

## Contexto
Depois do bootstrap, antes de qualquer módulo de negócio, construir os primitivos financeiros do caioimori-DS adaptados pra ApseOS. Garante que Story 3.x em diante não reinvente componentes.

## Acceptance Criteria

### AC1 — Money component
**Given** `<Money amount={1234.56} />`
**Then** renderiza `R$ 1.234,56` com `font-mono tabular-nums`; sinal negativo com `text-accent-danger`, positivo neutro (exceto quando prop `semantic="profit"`)

### AC2 — Margin component
**Given** `<Margin percent={12.5} />` e `<Margin percent={-3.2} />`
**Then** positivo: verde + ícone ↑; negativo: vermelho + ícone ↓; zero: neutro

### AC3 — KPIBlock
**Given** label + valor + delta (opcional)
**Then** renderiza label `text-xs text-secondary uppercase tracking-wide` + valor `text-3xl font-mono` + delta com cor semântica

### AC4 — DataTable denso
**Given** colunas + rows
**Then** row height 40px, header sticky, sort clicável, zebra subtle via `surface-default`, mobile responsive (scroll horizontal)

### AC5 — StatusPill
**Given** variant em `paid | pending | overdue | draft`
**Then** usa accent soft bg + accent text + `radius-badge` + `text-xs font-medium`

### AC6 — Dark mode paridade
**Given** toggle de tema
**Then** todos os 5 componentes acima renderizam sem quebrar contraste (WCAG AA)

### AC7 — Storybook local (ou page de preview)
**Given** `/design-system` route em `apps/web`
**Then** lista todos componentes com states (hover, disabled, loading)

## Scope IN
- `packages/shared/ui/finance/`: Money, Margin, KPIBlock, DataTable, StatusPill, Sparkline
